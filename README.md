# OENEXA Engineering Standards (`oenexa-standards`)

> **Global API Style Guide, Git Conventions, Code Linting & Quality Standards**  
> Governed by the Principal Software Engineering & Quality Assurance Councils.

## 1. Scope
Every repository in the OENEXA ecosystem must adhere to the standards maintained in this repository.

### Guidelines
- [API Style Guide](file:///C:/workspace/oenexarepo/oenexa-standards/api/api-style-guide.md): RESTful naming conventions, RFC 7807 Problem Details, gRPC protobuf standards, idempotency semantics.
- Commit Standards: Strict enforcement of [Conventional Commits](https://www.conventionalcommits.org/).
- Code Quality: Automated SonarQube & ESLint gates requiring >= 80% test coverage and zero critical vulnerabilities.
